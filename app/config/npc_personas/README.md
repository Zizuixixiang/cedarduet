# NPC 人设配置

此目录只存管理员提供的人设 JSON；仓库不附带生产人设。每个文件是一份：

```json
{
  "id": "stable_lowercase_id",
  "display_name": "对局中显示的名字",
  "persona": "供模型决定表达风格的几百字人设文本",
  "avatar": "optional_avatar.webp"
}
```

- `id` 必须稳定且全目录唯一，只能使用小写字母、数字、下划线、连字符，最长 64 字符。
- `display_name` 非空且最多 80 字符；`persona` 非空且最多 4000 字符。
- `avatar` 可省略；若存在，只能是头像目录根部的 png/jpg/jpeg/webp/gif 文件名。
  不允许目录分隔符、路径穿越或 SVG。头像目录用 `DUEL_NPC_AVATARS_DIR` 指定。
- 除本说明、`_schema.json`、不会被加载的 `_example.json` 与人设 `.json` 外，
  目录中不允许其他文件。
- 每局最多随机抽取四份且不重复；库存不足会拒绝创建，不会降级为重复 NPC。
- NPC 首要目标是理解规则并争取获胜；可以依据公开信息正常推理和估计，但不得把对手隐藏状态当作已知事实。
- NPC 不得以真实披露为目的直接报出自己的具体隐藏牌、骰子等私有状态；可以为了策略虚张声势、试探、模糊表达或作真假难辨的误导，吹牛骰子等玩法中的正常诈唬不受禁止。
- 人设只影响合理行动之间的选择、风险偏好和交流方式，不得为了维持性格故意走明显坏棋。合法行动必须由游戏规则引擎提供，模型不得生成或扩大合法行动集合。

测试人设只放在临时测试目录，不要把它们复制到这里充当生产内容。
`_example.json` 只用于展示格式，不属于运行库存，也不代表正式角色。
