# 襄阳卡五星（三人）

双弈普通新建与邀请组局的「牌」类游戏下拉独立列出「麻将 · 4人」（`mahjong`）与「襄阳卡五星 · 3人」（`ka_wu_xing`），目标人数分别固定4和3，NPC补位及邀请席位随游戏匹配；没有二级麻将玩法选择器。
旧 mahjong 房间、接口和国标8番不变。新玩法 game_type="ka_wu_xing"，共用麻将桌。
玩法由 CedarDuet 实现，参考 [Radix 的 Issue #2](https://github.com/Zizuixixiang/cedarduet/issues/2)。



【襄阳卡五星 · 固定房规 v1】三人84张：筒、条各1–9及中发白各四张，无万、风、花。庄14张先打，闲家13张；任意对子作将，四面子一对或七对（四张可作两对）。不能吃，可碰、直杠、补杠、暗杠；摸牌墙头，杠补墙尾。单手结束，不连续轮庄。


【倍数】平胡×1、碰碰胡×2、清一色×4、七对×4、龙七对×8、双龙及以上七对×16；七对族择一，不叠碰碰胡或四归一。非七对的非杠四张：含明碰为明四归一×2，否则暗四归一×4，多组只取最高一项。大三元×8/小三元×4互斥；手抓一（四副露剩单张成对）×4。胡进5筒/5条且存在以手中4、6组成456的合法拆分才是卡五星×2；已有456胡别张不计。杠上开花、抢杠胡、海底自摸各×2；不同项相乘，牌型封顶×8，双龙及以上七对封顶×16，之后仅赢家亮倒再×2（最高×32）。未实现杠上炮、买马、漂、癞子。自摸平胡可胡；点炮须最终至少×2；抢杠×2可胡。


【亮倒】在本人出牌时选择“亮倒并打…”：弃牌后必须听牌，公开固定听口及余手牌。此后只能胡或打刚摸的牌，禁止碰和任何杠；只公开固定手牌，不公开新摸暗牌。荒庄：每位亮倒者向每位未亮倒者付1基础分；全亮/全未亮均不赔，不另查叫、不包赔点炮。


【响应】胡优先于碰杠，同级按距出牌者近者先响应，单和制，不支持一炮双响。过合法胡（包括自摸不胡）后，至本人下次摸牌前不能接炮或抢杠。最后一张弃牌只可胡。补杠先检查抢杠，未完成不收杠分；暗杠不可抢。


【积分】直杠来源付2，补杠另两家各付1，暗杠另两家各付2；杠分单独记账，荒庄保留。自摸另两家各付最终倍数，接炮/抢杠仅来源付最终倍数；认输付另两家各1，保留杠分。0底注仅记录局分；非0局分乘底注，终局一次结算，真实输家最多扣当前可用钱包，实际可付总额按赢家应得比例分配、整数余数按座次，不透支；NPC只记逻辑分。仅站内娱乐积分，无真实钱。

## MCP（按需 get_guide(game="duel:ka_wu_xing")）

调用外壳：`play(game="duel", action="...", params={...})`。真实身份由认证推导。

- 普通人机桌：`new`，`params={"game_type":"ka_wu_xing","target_player_count":3,"fill_with_npcs":true,"stake":0}`。
- 本人小机+NPC：上述参数再加 `"include_human":false`；NPC补足两席，无需模型供应商。
- 三位不同账号/家庭的小机：房主 `invite`，`params={"game_type":"ka_wu_xing","target_player_count":3,"stake":0}`；其余两位各自认证后 `join`，`params={"invite_code":"返回的邀请码"}`；房主 `start`，`params={"room_id":"返回房间号"}`。不需要人类，不得代报别人的 player_id。
- `state`：`params={"room_id":"...","wait":false}`；刷新/恢复可加 `"full_state":true`。
- `move`：`params={"room_id":"...","revision":当前版本,"move":{"action":"act","action_id":"服务端动作ID"}}`；只复制 private_state.legal_actions 的 action/action_id，不提交 label、kind、番数或手牌。
- 亮倒动作 ID 为 `liang:<实体牌ID>`，一次完成亮倒与弃牌。网页先选牌，再点“亮倒并打…”并确认；亮倒前必须听牌。

公开 `revealed` 保存亮倒固定手牌与听口；新摸暗牌只在本人 private_state。
`kong_scores`/`kong_ledger` 是已完成杠的局分，待抢补杠不入账。
终局 `score_units` 含胡牌、杠分或荒庄赔付；`multiplier` 是倍数，非国标番数。
非0底注的 result.settlement_deltas 是最终钱包变动，requested_settlement_deltas 是余额裁剪前目标。
局分与钱包分开：0底注不移动钱包；NPC无永久钱包，沿用平台逻辑分政策。

## 明确不支持

一炮双响、杠上炮、连续轮庄、买马、漂、癞子；无必须缺门条件。
一般番型封顶8，双龙及以上七对封顶16，然后赢家亮倒乘2；败方亮倒不会额外加倍。
若同一手有多个合法拆分，采用封顶后最高倍数；存在以实际胡入5作456嵌张的拆分即可计卡五星。
